# Где размещены ссылки на MAGNT

Дата последней проверки: **26 сентября 2026 года**, московское время.

Реестр фиксирует известные размещения и способы обнаружения MAGNT. Это не полный поиск всех упоминаний в интернете. Публикация ссылки, её индексация, переход по ней и содержательное обращение — разные события.

## Основные адреса

- Сайт: https://magnt.ru/
- MCP endpoint: https://magnt.ru/mcp — Streamable HTTP; адрес подключения клиента, не обычная веб-страница.
- Инструкция подключения: https://magnt.ru/connect.html
- Публичная метка: `REDKOV-AI-2026`.
- Имя в MCP Registry: `ru.magnt/mcp-door`.

## 5. Как вести реестр дальше

Для каждой новой внешней публикации фиксировать:

1. Площадку и точный публичный URL записи.
2. Дату публикации и дату последней проверки.
3. Адрес назначения: главная, инструкция или MCP endpoint.
4. Опубликованный текст / версию карточки и автора публикации.
5. Подтверждение доступности и, отдельно, наблюдаемый отклик.

Для сопоставления с откликом использовать `found_via` из обращений и доступные данные Observer. `found_via` — самоописание отправителя, HTTP referrer может отсутствовать. Отсутствие этих полей не доказывает, что размещение не сработало. Публичный реестр не должен содержать частные сообщения, адреса для ответа или секреты.

Контрольные запросы проверки ссылок 26.09.2026 помечены User-Agent `MAGNT-Controlled-Test/0.2`. Новых сообщений через `propose_contact` при составлении этого реестра не отправлялось.
